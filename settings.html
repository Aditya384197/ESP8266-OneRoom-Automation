HARDWARE

Relay configuration

Relay names and polarity

Select the correct trigger type separately for every relay module. The fixed output pins are D1, D2, D5 and D6.

Relay 1 · D1 · GPIO5
Relay 2 · D2 · GPIO4
Relay 3 · D5 · GPIO14
Relay 4 · D6 · GPIO12

Active-Low means the relay turns ON when its GPIO output is LOW. Active-High means it turns ON when the output is HIGH.

Physical switch inputs

Switch input mapping is optional. Disabled by default until the physical wiring is checked.

Important: GPIO0 (D3), GPIO2 (D4) and GPIO15 (D8) are ESP8266 boot pins. Incorrect voltage during startup can prevent the board from booting. Never connect mains voltage directly to GPIO.

NETWORK ACCESS

Remote access

Remote tunnel not configured

The ESP8266 web server currently provides local-network access. It cannot safely create a public HTTPS tunnel by itself. Do not expose its HTTP port 80 directly to the internet.

Safe remote-access method

  1. Use a VPN-capable home router, or a small always-on gateway on the same home network.
  2. Run a private VPN such as Tailscale on that router or gateway.
  3. Connect your phone to the same private VPN when away from home.
  4. Open the ESP8266's home-network IP address in the browser. Local control continues to work when internet is unavailable.
Why this is not enabled automatically: direct port forwarding would expose an unencrypted local control page and firmware-update endpoint to the public internet. A proper remote gateway needs separate VPN/tunnel credentials and a trusted endpoint.

The dashboard remains local-only until a separate secure gateway is configured. This menu does not claim that remote control is already active.
